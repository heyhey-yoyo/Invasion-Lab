# v1.1.0 → v2.0.0 修改记录

## 科学与模型层

- 新增统一场景目录、几何构建和场景默认值。
- 新增场景感知事件、指标、结果模式、解释与推荐对照。
- 保留固定 seed 的确定性，并加入配置哈希和场景哈希。
- 增加 cohort、branch 和 leader 相关帧字段。
- 将拥堵 → 局部松动 → 解堵做成可检测相变。

## 运行与性能层

- 实时模拟使用固定 `1/30` 模拟秒步长。
- 限制后台恢复后的最大追帧，避免巨量补算。
- 新增独立 Batch Worker；每个格点运行多个 seed，并发送逐格进度。
- 批量扫描降低细胞数和模拟时长，不复制实时渲染数据。

## 产品与界面层

- 新增四个实验问题卡片。
- 场景切换时同步几何控制、指标文案、扰动按钮、观察文字和结果分类。
- Lab 模式显示配置与场景哈希。
- 侵袭地图显示主导模式、seed 一致度和可点击代表格点。
- 保留事件时间线、回放、JSON/CSV/PNG、分享链接和本地保存。

## 兼容性

- 保留原 preset ID 和 URL 参数。
- 新增 `q` 场景参数；缺失时迁移到 `narrow-gap`。
- 优先读取 `iwt-project-v2`，找不到时迁移 `iwt-project-v1`。
- v2 使用新的本地存储键，不覆盖 v1 数据。

## 部署与维护

- PWA 缓存升级到 v2 资产清单。
- 添加自定义 404 页面。
- 添加敏感文件与凭据模式扫描。
- GitHub Actions 使用最小权限并固定到完整 SHA。
- 增加 Cloudflare、GitHub Pages、Netlify、Vercel 部署说明。
