# v2.0 已知限制

1. 当前力学层是二维软粒子近似，不是 Cellular Potts Model，也没有真实细胞膜像素形变。
2. 参数为归一化教学参数，没有用实验单位校准。
3. 结果分类是规则式、场景感知分类器，不是经过训练的病理或临床模型。
4. 批量地图的 seed 数最多 5，显示一致度而不是统计置信区间。
5. 本地项目保存配置、结果和摘要，不保存所有完整帧；页面刷新后不能恢复逐帧回放。
6. 移动端会受 CPU 和内存差异影响；尚未完成真实设备矩阵。
7. 未完成 Safari、Firefox、Chromium 的完整人工视觉对比与屏幕阅读器人工测试。
8. v2 schema 2 导出不能由 v1 自动读取。
9. 还未接入实验数据、Artistoo 或其他独立模型进行定量交叉验证。
