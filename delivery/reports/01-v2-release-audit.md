## v2.0 核心跃迁

1. 单场景模型升级为四场景目录：狭窄缺口、肿瘤出芽、Leader–Follower、拥堵与解堵。
2. 配置、行为人格、场景、结果分类、事件、Worker 和批量扫描形成明确模块边界。
3. 侵袭地图从启发式着色改为真实多随机种子模拟。
4. 实时模拟与批量扫描使用两个独立 Worker，批量任务不会阻塞实时实验线程。
5. 每份结果记录应用、模型、场景和 schema 版本，以及配置哈希、场景哈希和随机种子。
6. v1 URL 参数和本地配置可迁移到 v2 narrow-gap 场景。
7. 增加自定义 404、安全响应头、敏感信息扫描和可部署 CI。

## 行为与格式变化

⚠️ 算法变化：结果分类现在按场景解释，同一组通用指标可能映射到不同教学模式。

⚠️ 数据格式变化：结果 schema 升级到 2；帧 stride 从 9 增加到 11；几何改为 `meta.geometry`。

⚠️ UI 变化：Play / Explore / Lab 保留，但增加场景选择、动态扰动、场景指标和多随机种子地图。

⚠️ 性能变化：批量地图执行真实模拟，因此比 v1 静态着色消耗更多 CPU；任务已移入独立 Worker，并限制网格、种子数、细胞数与时长。

## 未发现或不适用

- 无后端、数据库、认证、Cookie、远程 API 或用户上传，因此 CSRF、SQL 注入、SSRF 和服务端授权不适用。
- 无第三方运行时依赖，因此本版本不存在依赖树升级或客户端供应链包体风险。
- 无患者数据或生产数据库迁移。

## 科学边界

当前引擎仍是二维软粒子近似，不是 Artistoo Cellular Potts Model，不提供患者特异、诊断、预后或治疗建议。场景结果是教学与机制假设演示，不能解释为实验验证或临床预测。
