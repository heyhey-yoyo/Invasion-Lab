# Invasion Wind Tunnel v2.0 交付物

- `project/`：完整 v2.0 源码，不含 `dist` 和 `node_modules`。
- `release/`：v2.0 源码包和可直接部署的静态包。
- `baseline/`：v1.1.0 源码与静态回滚包、基线 SHA。
- `reports/`：审查、变更、测试、部署、迁移、回滚、参考资料和限制。
- `diffs/`：从 v1.1.0 到 v2.0 的完整文本补丁与文件清单。
- `checksums.txt`：交付文件 SHA-256。

推荐先阅读 `reports/01-v2-release-audit.md`、`reports/03-test-results.md` 和 `reports/04-deployment-guide.md`。
