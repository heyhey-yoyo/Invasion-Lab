# 验证范围与维护基线

模型和 schema 版本独立于视觉维护；以下自动化数量来自 2026-09-13 的既有维护验收，本次文档整理没有重新执行模型测试。

## 自动化范围

`npm test` 当前包含 33 项测试，覆盖：

- 配置消毒、版本、处理组、哈希和旧版迁移；
- 细胞帧与 ECM 帧的固定种子确定性；
- v4 stride 20、ECM 快照和可序列化几何；
- 面积守恒、非零形变、显式核应变和接触网络；
- 四预设差异化结果和四场景默认教学基线；
- 解堵扰动、动态 Leader 补位和出芽事件；
- Worker 播放速度、运行标识隔离与最终结果 exactly-once；
- 多随机种子地图的确定性与进度；
- 配对种子对照的确定性、探索性 t 区间与右删失计数；
- 阻断 ECM 降解降低重塑面积；
- 提高环境阻力降低运动性/通过；
- 抑制 Leader 降低路线跟随一致度和牵引不对称；
- 首次接触必须来自实际边界接触，Leader 形成不得全局改写 follower 路线。

## 科学不变量

- 所有形状应变下 `πab = πR²`；
- 同模型版本、配置和种子产生相同细胞帧、ECM 帧和事件；
- 对照组与处理组共享同一组配对种子；
- ECM 损伤不会自发增加，必须由细胞活动触发；
- 出芽簇大小为 1–4 个细胞；
- 结果包含科学边界声明。

## 界面维护验收

npm run check 汇总数据校验、静态扫描、测试、构建与 HTTP smoke。既有浏览器验收覆盖桌面/平板/手机以及 DPR 1/2/3：模型保持 960×540 逻辑空间，缓冲按实际 CSS 矩形与上限为 2 的 DPR 缩放，指针映射使用同一基准。页眉在文档流中，1280px 内容区居中、品牌左对齐；桌面模式切换与说明按钮共同靠右，手机模式导航保留在底部。

样式查询参数、Service Worker 缓存和预缓存地址必须同步。Windows Chromium 的结果不能视为 Firefox/Safari 像素级兼容认证。
