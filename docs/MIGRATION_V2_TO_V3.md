# v2.0.0 → v3.0.0 迁移说明

## 兼容读取

- URL 参数名称继续兼容；
- v3 本地保存键为 `iwt-project-v3`；
- 载入时依次尝试 v3、v2、v1；
- 旧配置通过 `makeConfig()` 重新钳制并生成 v3 哈希。

## 破坏性变化

- `CONFIG_SCHEMA_VERSION`: 2 → 3；
- `RESULT_SCHEMA_VERSION`: 2 → 3；
- frame stride: 11 → 14；
- `MODEL_VERSION`: 软粒子引擎 → 主动可变形细胞形状张量引擎；
- 场景版本升级到 3.0.0；
- 结果新增 `model` 元数据和形状/核/接触指标。

## 帧字段

v2 的 `stretch` 被重新定义并扩展为物理状态：

- 字段 7：面积守恒形状应变；
- 字段 11：形状长轴角度；
- 字段 12：细胞核应变；
- 字段 13：当前接触数。

第三方工具必须按 `meta.stride` 和版本解析。

## 科学语义变化

- `deformability` UI 名称改为“细胞柔顺性”，同时影响边界与细胞核响应；
- `adhesion` UI 名称改为“细胞连接强度”；
- `alignment` UI 名称改为“群体引导”；
- “压力”改为接触应力代理；
- 肿瘤出芽簇由 2–10 个细胞改为 1–4 个细胞；
- 迁移目标由固定目标向量改为绕障碍扩散型引导场。

## 回滚

v3 不覆盖 v2 静态源码包。需要回滚时部署 v2.0.0 包即可。v2 不会读取 `iwt-project-v3`。
