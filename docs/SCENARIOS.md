# v4.0 场景目录

## 1. 狭窄缺口

- 问题：细胞会堵住，还是穿过去？
- 默认实验预设：协同推进者
- 扰动：扩大缺口、降低细胞连接、提高细胞柔顺性
- 主要事件：首次接触、首次通过、50% 通过、拥堵、断裂、单细胞逃逸
- 典型结果：拥堵、集体推进、肿瘤出芽、单细胞逃逸、指状侵袭

## 2. 肿瘤出芽

- 问题：什么时候会从主体边缘长出小芽？
- 默认实验预设：边缘出芽者
- 扰动：打开 ECM、松动边缘、增强边缘运动
- 主要事件：首次接触、首次形成 bud、首次越界、断裂、单细胞逃逸
- 典型结果：稳定团块、肿瘤出芽、指状侵袭、单细胞逃逸

## 3. Leader–Follower

- 问题：一个领头细胞能带群体走对分叉吗？
- 默认实验预设：协同推进者
- 扰动：移除 leader、切换路线、增强跟随
- 主要事件：leader 通过、leader 丢失、leader 补位、两个分支同时占据
- 典型结果：leader 引导、分叉迁移、引导失效、集体推进

## 4. 拥堵与解堵

- 问题：高密度群体何时会突然流动？
- 默认实验预设：紧密拥堵者
- 扰动：局部松动、提高细胞柔顺性、施加推动
- 主要事件：拥堵、解堵、首次到达、50% 到达
- 典型结果：拥堵、解堵、集体流动

## 扩展新场景的最低要求

新增场景必须提供：

1. 唯一 ID 与场景版本；
2. 明确科学问题和非临床边界；
3. 默认实验预设、几何、初始条件和判定边界；
4. 不超过三个 Play 模式扰动；
5. 事件、指标文案和结果分类；
6. 默认结果回归测试；
7. 至少一个扰动效果测试；
8. 批量地图可运行性测试。
