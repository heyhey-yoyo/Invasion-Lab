# v4 科学范围与禁止性声明

## 可以做

- 比较连接、柔顺性、群体引导、几何约束和离散环境处理的定性影响；
- 观察细胞形状、核应变、接触网络、动态 Leader、细胞状态和 ECM 重塑；
- 使用相同随机种子进行单因素配对对照；
- 使用多随机种子判断模型内趋势是否稳定；
- 教学展示拥堵、解堵、集体推进、出芽、单细胞逃逸和 Leader–Follower。

## 不可以做

- 临床预测、患者分层、预后判断或治疗决策；
- 将归一化参数映射为具体基因、药物剂量、MMP 活性或真实物理单位；
- 将二维结果解释为三维组织定量结论；
- 将探索性区间称为临床置信区间；
- 声称模型等同于 CPM、DPM、相场、顶点、有限元或真实细胞；
- 将接触应力、ECM 损伤或出芽计数直接替代实验/病理测量。

## v4 相对 v3 的可信改进

- ECM 从静态视觉层升级为双向作用的模型状态；
- Leader 从预设身份升级为动态前缘竞争和更替；
- Follower 方向通过接触网络传播；
- 黏附考虑近似接触长度；
- 新增自动细胞状态和配对种子对照。

这些改进增强了内部一致性和可解释性，但仍未经过真实显微数据校准。
