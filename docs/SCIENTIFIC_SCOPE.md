# 科学范围与限制

## 可以用于

- 解释黏附、形变、方向持续性、邻居对齐、leader 影响、几何受限和拥堵的定性关系；
- 比较单变量对照实验；
- 教学展示群体推进、出芽、单细胞逃逸、分叉和解堵；
- 生成可复现的机制演示和参数扫描。

## 不可以用于

- 患者特异预测；
- 诊断、预后或治疗建议；
- 将归一化参数解释为真实生物量；
- 将结果比例解释为临床发生概率；
- 替代体外、动物或临床验证；
- 宣称当前软粒子模型等同于 Artistoo、CPM、BIO-LGCA 或真实组织力学。

## 当前简化

- 二维；
- 单一主要细胞群；
- 无细胞增殖、死亡、药物、免疫或克隆演化；
- 组织障碍为简化矩形几何；
- 趋化为目标方向偏置，不求解真实扩散方程；
- 形变为有效半径与可视拉伸近似；
- 事件和分类使用透明规则阈值。

## 结果解释原则

结果文案必须使用“在当前模型规则下”“这次模拟中”等限定语，不将一次运行外推为一般生物学定律。批量地图的一致度表示有限随机种子之间的一致性，不是统计置信区间或临床概率。
