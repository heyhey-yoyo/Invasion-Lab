# v2.0 模型说明

## 科学定位

当前模型是二维、定性、归一化的群体迁移机制演示。它不使用患者数据，不拟合临床终点，也不输出疾病风险或治疗建议。

## 状态变量

每个细胞记录：

- 位置与速度；
- 前一时刻方向；
- 局部压力；
- 邻居数；
- 是否到达场景判定边界；
- 是否为 leader；
- 边缘 cohort；
- 分支编号；
- 形变显示量；
- 是否相对孤立。

## 方向更新

细胞的期望方向由以下因素组成：

```text
desired =
  chemotaxis / scenario target
  + persistence
  + neighbor alignment
  + local cohesion
  + leader influence
  + stochastic noise
```

方向向量只产生驱动力，不直接改写位置。

## 力学近似

- 近距离细胞产生排斥；
- 中距离细胞按黏附强度产生吸引；
- 不同 cohort 之间可降低耦合；
- 细胞与矩形组织障碍发生圆—矩形碰撞；
- 形变能力影响有效半径、受限开口中的运动能力和碰撞后的恢复；
- 速度使用阻尼和最大速度限制；
- 位置使用固定时间步积分。

这不是 Cellular Potts Model。当前细胞是可拉伸显示的软粒子，不具有真实像素边界、面积约束或周长能量。

## 场景适配

### 狭窄缺口

单一屏障和中央开口。主要变量是开口宽度、黏附、形变和协同。

### 肿瘤出芽

前缘 cohort 具有轻微运动偏置，并可降低与主体的黏附耦合。小型连通分量用于识别 bud。

### Leader–Follower

两个出口构成分叉。leader 选择分支，follower 在一定距离内受到 leader 位置和目标方向影响。移除 leader 后，高对齐条件下可由前沿细胞补位。

### 拥堵与解堵

高密度团块进入受压缩通道。低形变条件下前沿停滞并积累压力；永久局部松动或高形变可触发前沿推进，被记录为解堵事件。

## 连通分量与指标

细胞中心距离小于阈值时视为连接。由此计算：

- 最大连通分量占比；
- 分裂片段数量；
- 小型 bud 数量；
- 孤立通过比例；
- 分支占据数；
- leader 跟随一致度。

其他指标包括通过率、首次事件时间、平均压力、平均速度、归一化运动指数、前沿位置与前沿粗糙度。

## 结果分类

分类规则按场景分别定义。规则是透明、版本化的教学判定，不是训练得到的临床分类器。

## 随机性

使用确定性的 32 位伪随机数生成器。配置中的 seed 被限制到 `1..2^32-1`。同一模型版本、配置与 seed 会产生相同帧和事件。
